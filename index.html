Configuration examples

Open an example to load a separate viewer using a local copy of a mocked up version of what could be the British Museum's Caryatid manifest. Images are served by the British Museum.

Hide the URL bar

The URL input and Load button are hidden, but dropping a manifest link still works.

new IIIFViewer('#example-no-url', {
  manifestUrl: './examples/caryatid-manifest.json',
  showUrlInput: false,
});
Disable manifest drops

The URL bar remains available, but dropping a manifest link does not load it.

new IIIFViewer('#example-no-drop', {
  manifestUrl: './examples/caryatid-manifest.json',
  allowManifestDrop: false,
});
Start with fewer controls

The URL bar and manifest drops are disabled, and the sidebar starts closed. The Info button can still open it.

new IIIFViewer('#example-minimal', {
  manifestUrl: './examples/caryatid-manifest.json',
  showUrlInput: false,
  allowManifestDrop: false,
  showSidebar: false,
});
Hide external viewer links

The Metadata tab remains available without links to external IIIF tools.

new IIIFViewer('#example-no-external-viewers', {
  manifestUrl: './examples/caryatid-manifest.json',
  externalViewers: false,
});
Download an image

Enable a size-selectable full-image download. The image provider's rights and size restrictions still apply. The British Museum's policies are restrictive...

new IIIFViewer('#example-download', {
  manifestUrl: './examples/caryatid-manifest.json',
  showUrlInput: false,
  allowManifestDrop: false,
  physicalRuler: true,
  imageDownload: { widths: [300, 600], maxPixels: 4000000 },
  showSidebar: false,
});
